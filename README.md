# ركن الشوكلاتة - موقع الكافيه

موقع إلكتروني كامل لكافيه **ركن الشوكلاتة** مع لوحة تحكم كاملة.

## المميزات

- تصميم عربي حديث (RTL) بألوان الشوكولاتة
- 7 أقسام رئيسية + إمكانية إضافة أقسام جديدة
- إدارة كاملة للمنتجات (إضافة / تعديل / حذف)
- رفع الصور مباشرة من الجهاز أو عبر رابط
- تغيير اسم الموقع والشعار والألوان
- حفظ البيانات محلياً في المتصفح (LocalStorage)
- تصدير / استيراد البيانات بصيغة JSON
- متجاوب مع الجوال والكمبيوتر

## طريقة النشر (Static Hosting)

هذا الموقع **ثابت بالكامل** (Static Site) ولا يحتاج خادم أو قاعدة بيانات.

### خيارات الاستضافة المجانية الموصى بها:

1. **Netlify** (الأسهل)
   - ادخل إلى [netlify.com](https://netlify.com)
   - اسحب مجلد المشروع كاملاً إلى الموقع
   - احصل على رابط دائم فوراً

2. **Vercel**
   - ادخل إلى [vercel.com](https://vercel.com)
   - ارفع المجلد أو اربطه بـ GitHub

3. **GitHub Pages**
   - ارفع الملفات إلى مستودع GitHub
   - فعّل GitHub Pages من الإعدادات

4. **Cloudflare Pages** أو أي استضافة عادية (cPanel / Hostinger / Namecheap...)
   - ارفع محتويات المجلد إلى `public_html` أو المجلد الرئيسي

### هيكل الملفات

```
rukn-alshukulata-site/
├── index.html          ← الملف الرئيسي (يحتوي على كل شيء)
└── README.md           ← هذا الملف
```

الملف `index.html` يحتوي على:
- HTML + CSS (Tailwind عبر CDN) + JavaScript
- كل المنطق والبيانات الافتراضية
- لا يحتاج أي ملفات إضافية ليعمل

## ملاحظات مهمة

### حول الصور
- الصور الافتراضية تأتي من Unsplash (تحتاج إنترنت)
- عند رفع صورة من الجهاز يتم تحويلها إلى Base64 وتُحفظ داخل LocalStorage
- للحصول على أداء أفضل على الموقع العام، يُفضل رفع الصور على خدمة مثل:
  - [ImgBB](https://imgbb.com)
  - [Postimages](https://postimages.org)
  - أو استضافتك الخاصة، ثم وضع الرابط

### حول حفظ البيانات (LocalStorage)
- التعديلات تُحفظ في متصفح الزائر فقط
- كل جهاز / متصفح له نسخته الخاصة
- إذا أردت مشاركة التعديلات بين أجهزة متعددة أو جعلها دائمة لجميع الزوار، ستحتاج لاحقاً إلى:
  - Backend بسيط (Firebase / Supabase / PocketBase)
  - أو قاعدة بيانات

النسخة الحالية مناسبة تماماً للاستخدام الشخصي أو العرض أو المتاجر الصغيرة التي يديرها شخص واحد من نفس الجهاز.

### كلمة المرور / الحماية
لوحة التحكم مفتوحة حالياً (بدون كلمة مرور).  
إذا أردت إضافة حماية بسيطة يمكن تعديل الكود لاحقاً.

## التخصيص

افتح `index.html` بأي محرر نصوص وعدّل:
- البيانات الافتراضية داخل `defaultData`
- الألوان في إعدادات Tailwind
- النصوص في الهيرو والفوتر

## الدعم

تم إنشاء الموقع بالكامل ليعمل بدون أي تبعيات خارجية معقدة.
فقط ارفع `index.html` وسيعمل.
